Geo Viewer — курсова робота
Опис проєкту

Geo Viewer — це веб-застосунок для відображення геопросторових даних на інтерактивній карті. Система дозволяє користувачу вводити геодані у форматах WKT або GeoJSON, після чого вони обробляються на серверній частині та візуалізуються на карті у браузері.

Функціонал
введення геопросторових даних (WKT / GeoJSON)
автоматична конвертація форматів на сервері
відображення об’єктів на інтерактивній карті
підтримка геометрій:
точки
лінії
полігони
робота з шарами (додавання/видалення)
зміна базової карти (OpenStreetMap, Esri, CartoDB)
обчислення довжини ліній та площі полігонів
вибір одиниць вимірювання
Технології
Клієнтська частина:
HTML
CSS
JavaScript
Leaflet
Turf.js
Серверна частина:
Java
Spring Framework
Архітектура

Система побудована за клієнт-серверною архітектурою:

Користувач вводить геодані у веб-інтерфейсі
Дані надсилаються на сервер (Spring Boot)
Сервер виконує парсинг і конвертацію у GeoJSON
Результат повертається клієнту
Leaflet відображає дані на карті
Запуск проєкту
Backend:
запустити Spring Boot застосунок
сервер працює на http://localhost:8080
Frontend:
відкрити index.html у браузері
або запустити через локальний сервер (рекомендовано)
Приклад даних
WKT:
POINT(24.031111 49.842957)
GeoJSON:
{
  "type": "Point",
  "coordinates": [24.031111, 49.842957]
}
Призначення

Проєкт створено в межах курсової роботи для демонстрації принципів роботи з геопросторовими даними та їх візуалізації у веб-середовищі.
